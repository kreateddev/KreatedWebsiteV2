# assets/

**Empty by design.**

Nothing is copied out of V1 or anywhere else until an approved concept needs it *and*
`docs/ASSETS.md` records that the asset may be used.

| Directory | Holds |
|---|---|
| `brand/` | Kreated's own marks, wordmark files, fonts |
| `projects/` | Client project media — logos, real screenshots |
| `photography/` | Founder and project photography |
| `generated/` | Produced signature and supporting visuals (Steps 4 and 7) |

Full inventory, with AVAILABLE / OUTDATED / FORBIDDEN / MISSING / NEEDS RECAPTURE status for every
known asset, is in `docs/ASSETS.md`.

🚫 Do not process the approved monogram source (`KWLG.png`) early. See `docs/ASSETS.md` §1.
